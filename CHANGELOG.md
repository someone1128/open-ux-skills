# Changelog

All notable changes to this project will be documented in this file.

This project uses a simple changelog format instead of pretending every Markdown tweak needs a ceremony.

## 0.2.0 - 2026-06-06

### Added

- Added the unified `hzy-ux-` skill prefix.
- Added `hzy-ux-accessibility-review`.
- Added `hzy-ux-mobile-responsive-review`.
- Added `hzy-ux-information-architecture-review`.
- Added `hzy-ux-copy-microcopy-review`.
- Added `CONTRIBUTING.md`.
- Added `templates/SKILL_TEMPLATE.md`.
- Added `test-cases/` for expected skill behavior.

### Changed

- Expanded `hzy-ux-pattern-case-library` into a broader interaction pattern library.
- Updated `README.md` with the prefixed skill names and recommended workflows.
- Updated `skills.json` with the prefixed skill list.

### Removed

- Removed legacy unprefixed skill paths.

## 0.1.0 - 2026-06-06

### Added

- Initial product-agnostic UX skills.
- English-first, Chinese-supported documentation.
- Basic examples for AI creative generation and guided survey flows.
