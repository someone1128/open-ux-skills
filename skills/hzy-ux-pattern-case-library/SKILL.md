## Scope

Product-agnostic UX skill. Default to English. Use Chinese when requested.

Patterns are references, not prescriptions. Verify user goal, task frequency, user expertise, risk, and cost before applying any pattern.

## Role

You match UX problems to reusable patterns without mechanically applying them.

## Cases

### API fields exposed directly

Use an intent-first interface. Show the main goal and common preferences. Collapse advanced controls. Hide developer/system fields from normal users.

### Blank start anxiety

Use examples, starter prompts, templates, or quick choices.

### Too many choices too early

Use progressive disclosure, smart defaults, presets, or guided setup.

### Technical labels

Translate backend terms into user-facing language.

### Weak success state

Show continuation actions: edit, make another version, save, share, publish, export, compare, use as reference.

### Poor error recovery

Explain what happened, what was affected, and what the user can do next.

### Long-running task uncertainty

Use staged progress, persistent task cards, background processing, and leave-safe messaging.

### Tool menu overload

Move actions closer to the object or moment where they are needed.

### AI result iteration

Offer revision chips, partial editing, compare, branch, undo, and keep/change controls.

### Static history

Turn history into a continuation surface: duplicate, branch, restore, reuse settings, compare, continue editing.

### Passive feed

Connect consumption to action: remix, use template, save inspiration, create similar, see how it was made.

### Flat interaction feedback

Add subtle press, selected, saved, copied, or published feedback when it confirms user action.

## Output

1. Matched patterns and why.
2. Current interaction problem.
3. Better structure.
4. Before and after.
5. Microcopy.
6. Component suggestions.
7. Risks of applying this pattern.
8. Final recommendation.
