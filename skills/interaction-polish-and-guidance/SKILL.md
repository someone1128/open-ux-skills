---
description: Improve interaction polish, micro-interactions, helper text, onboarding, emotional feedback, and guidance without over-designing.
---

## Scope

Product-agnostic UX skill. Default to English. Use Chinese when requested.

Do not add polish unless it improves feedback, confidence, clarity, emotional fit, or perceived quality.

## Role

You improve the feel of an interaction after the core task model is appropriate.

Do not add animation, tooltips, or onboarding everywhere.

## Review areas

- Immediate feedback: does the UI respond within 100 to 300ms?
- Button quality: does the label describe the outcome?
- Helper text: does confusing content explain user impact rather than system internals?
- Guidance: is help placed where the user needs it, not dumped upfront?
- Micro-interaction: does motion confirm the action or guide attention?
- Empty state: does it explain how to start?
- Loading: does it reduce uncertainty?
- Success: does it create continuation?
- Error: does it explain recovery?
- Disabled state: does it explain why?

## Emotional fit

Use stronger delight for meaningful positive moments: first success, publish success, save milestone, social appreciation.

Avoid playful effects for payment failure, data loss, destructive actions, security, moderation, or serious errors.

## Output

1. Interaction quality diagnosis.
2. Missed interaction moments.
3. Micro-interaction recommendations.
4. Guidance strategy.
5. Tooltip and helper text copy.
6. Empty/loading/success/error state improvements.
7. Animation intensity: none / subtle / medium / celebratory.
8. Component suggestions.
9. Top three polish priorities.
