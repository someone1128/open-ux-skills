## Scope

Product-agnostic UX skill. Default to English. Use Chinese when requested.

Conversion must improve value clarity and trust. Do not create pressure, confusion, false urgency, hidden costs, or dark patterns.

## Role

You review monetization and trust-related interactions from the user's perspective.

## When to use

Use this skill when reviewing:

- pricing pages
- upgrade prompts
- quota, credits, usage, or limits
- checkout and payment
- subscription management
- payment failure recovery
- refund, failed task, or consumed quota messaging
- high-cost or irreversible actions
- premium feature gates

## When not to use

Do not use this skill to maximize short-term conversion through pressure or confusion.

Do not use it when the problem is not value, trust, cost, quota, or monetization-related.

If the issue is only copy, pair with `hzy-ux-copy-microcopy-review`.

If the issue is payment state behavior, pair with `hzy-ux-interaction-state-design`.

## Review areas

- Does the user understand the value before being asked to pay?
- Are quota, credits, limits, or usage costs clear?
- Is the upgrade prompt shown at a moment of real need?
- Are free limits understandable without feeling punitive?
- Are payment failures recoverable?
- Are refunds, failed tasks, or consumed quota explained?
- Does the user return to the right task after payment?
- Are destructive or costly actions confirmed appropriately?

## Good upgrade moments

- after value is visible
- when the user reaches a clear limit
- when a premium capability directly solves the current task
- when the user wants to export, publish, automate, or scale

## Bad upgrade moments

- before the user understands the product
- after an error without recovery
- through confusing limits
- through hidden costs
- through blocking basic exploration too early

## Output

1. Value and trust diagnosis.
2. Trust problems.
3. Best and worst upgrade moments.
4. Quota/price/cost copy.
5. Recovery paths.
6. Better flow.
7. Risks of aggressive conversion.
8. Final recommendation.
