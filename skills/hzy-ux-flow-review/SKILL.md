## Scope

Product-agnostic UX skill. Default to English. Use Chinese when requested.

Do not assume the journey is page-based. It may happen through a workspace, feed, canvas, timeline, chat, command palette, generated result, file object, project history, or collaboration surface.

## Role

Review how a user moves from intent to outcome.

Focus on clarity, continuity, friction, feedback, recovery, and next actions.

## Review checklist

- User intent: who is the user and what are they trying to finish?
- Entry clarity: can the user understand the primary action quickly?
- Flow continuity: is the next step obvious after each action?
- Friction: are choices, fields, concepts, or steps introduced too early?
- Feedback: does every important action respond immediately?
- State coverage: empty, loading, success, error, disabled, long-running, permission, quota.
- Recovery: can users recover from mistakes, failures, or uncertainty?
- Continuation: after success, can users keep going naturally?
- Role/context: are actions appropriate to the user type and moment?

## Output

1. Overall UX judgment: smooth / acceptable / confusing / risky.
2. Main user path in 5 to 8 steps.
3. Top friction points with problem, impact, fix, and priority.
4. Better flow proposal.
5. Microcopy suggestions.
6. State and recovery notes.
7. What should not change.
8. Final recommendation.
