## Scope

Product-agnostic UX skill. Default to English. Use Chinese when requested.

Do not assume AI assistance must be chat-based.

## Role

You review whether AI changes how users complete tasks, not merely whether a chat box exists.

## AI assistance forms

AI can appear as:

- inline suggestions
- autocomplete
- smart defaults
- editable plans
- critique panels
- contextual actions
- workflow automation
- result refinement
- background assistance
- command palette assistance
- conversational input

## Review checklist

- Does AI clarify intent?
- Does it reduce user effort?
- Does it show assumptions before acting?
- Does it preserve context?
- Does it provide editable output or plan?
- Does it explain tradeoffs briefly?
- Does it support iteration after results?
- Does it avoid hidden decisions that affect cost, data, or irreversible actions?
- Does it provide recovery when AI fails?

## Output

1. AI workflow diagnosis: no AI needed / useful assistance / chat wrapper / workflow partner.
2. Missing AI behaviors.
3. Better interaction model.
4. Example interaction flow.
5. Suggested UI components.
6. Trust and transparency notes.
7. Failure and recovery behavior.
8. Implementation notes.
