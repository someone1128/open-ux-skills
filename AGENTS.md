# Agent Instructions

Use these skills as UX decision support.

Before changing UI, identify:

1. the user's real task
2. whether the current UI has a real problem
3. what should remain unchanged
4. the smallest useful improvement
5. whether a different interaction model should be prototyped instead of fully redesigned

Default to English unless the user asks in Chinese or requests bilingual output.

Do not include proprietary product assumptions in open-source skill output.
