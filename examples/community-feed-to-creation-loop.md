# Example: Community Feed to Creation Loop

## Situation

A product has a community feed where users browse posts or outputs.

The feed supports passive consumption, but it does not help users start their own work.

## Current flow

1. User opens the feed.
2. User browses content.
3. User may like, save, or share.
4. User leaves or manually starts elsewhere.

## Better flow

1. User opens the feed.
2. User discovers interesting content.
3. Content cards expose action-oriented options such as use as template, create similar, remix, save inspiration, or see how it was made.
4. User starts creation from the content context.
5. The feed becomes a discovery-to-action surface.

## Pattern references

- Passive feed
- Tool menu overload
- Hidden value after generation
- Flat interaction feedback

## Validation metrics

- feed-to-create click rate
- save inspiration rate
- template/remix usage
- creator follow rate
- session depth after feed interaction
